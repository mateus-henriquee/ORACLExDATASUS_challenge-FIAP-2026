Como funciona

01

Acesse a plataforma

Entre com seu perfil: Executivo, Analítico ou Leigo — e explore os dados do SUS prontos para análise.

02

Dados carregados automaticamente

O pipeline busca dados reais do DATASUS via pysus, transforma e carrega no Oracle XE automaticamente a cada mês.

03

Análise em tempo real

Queries otimizadas com índices no Oracle retornam milhões de registros em menos de 1 segundo.

04

Insights e relatórios

Gere relatórios por município, hospital, faixa etária ou período. Exporte em PDF ou CSV com um clique.

Etapa 01

Coleta

O pipeline busca automaticamente os arquivos do SIH-SUS no DATASUS via API pysus.

Etapa 02

Transformação

Os dados brutos são limpos, deduplicados por AIH e enriquecidos com faixa etária e sexo.

Etapa 03

Data Lake

Os arquivos .parquet são armazenados no OCI Object Storage como camada de histórico.

Etapa 04

Carga no Oracle

Staging + MERGE SQL garante idempotência — nunca duplica registros mesmo rodando várias vezes.

Etapa 05

Dashboard

FastAPI serve os dados em tempo real para os três perfis de usuário com autenticação por sessão.

Perguntas frequentes

Tudo que você precisa saber antes de entrar na plataforma.

Sim. Todos os dados vêm de fontes oficiais do governo federal: o SIH-SUS (Sistema de Informações Hospitalares do SUS) via DATASUS, o CNES (Cadastro Nacional de Estabelecimentos de Saúde), o SIGTAP (Tabela de Procedimentos) e o IBGE. Nenhum dado é simulado ou inventado.
A plataforma roda localmente no seu computador. Você precisa ter Python 3.12+, Oracle XE 21c e as dependências instaladas via pip. O setup completo está documentado no README do repositório. Após a instalação, basta rodar um comando para subir o servidor.
Existem três perfis: Executivo (visão financeira e comparativos), Analítico (gráficos detalhados e análise por dimensão) e Leigo (IA conversacional que responde perguntas sobre os dados em linguagem natural). Cada perfil acessa dashboards e funcionalidades diferentes.
Do SIH-SUS via biblioteca pysus — carregamos 4 competências de 2024 (fevereiro, junho, agosto e dezembro) para o estado de São Paulo. Cada competência tem entre 220 mil e 244 mil internações. O pipeline suporta expansão para outros estados e períodos.
